TAURUS PROJECT CONTROL V26 — REPLACEMENT UPLOAD

1. Unzip this package on your computer.
2. Upload the extracted taurusprojectcontrol-professional-v26 folder to the taurusprojectcontrol GitHub repository.
3. Confirm this exact GitHub path exists:
   taurusprojectcontrol-professional-v26/package.json
4. Commit the changes to main.
5. No new Supabase SQL migration is required for v26 if migrations 0001 through 0008 are already applied.
6. Keep the Vercel Root Directory exactly as:
   taurusprojectcontrol-professional-v26
7. Keep the existing Vercel/Supabase variables and add PROJECT_CONTROL_URL, RESEND_API_KEY and PROJECT_NOTIFICATION_FROM_EMAIL for update emails.
8. Redeploy Vercel.

The v26 package is intentionally kept compact for simpler GitHub web upload.
Never upload passwords, database passwords, Supabase secret keys, .env files or .env.local files to GitHub.
