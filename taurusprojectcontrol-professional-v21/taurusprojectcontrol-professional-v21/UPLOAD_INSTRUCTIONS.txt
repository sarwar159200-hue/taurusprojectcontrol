TAURUS PROJECT CONTROL V20 — REPLACEMENT UPLOAD

1. Unzip this package on your computer.
2. Upload the extracted taurusprojectcontrol-professional-v20 folder to the taurusprojectcontrol GitHub repository.
3. Confirm this exact GitHub path exists:
   taurusprojectcontrol-professional-v20/package.json
4. Commit the changes to main.
5. No new Supabase SQL migration is required for the V20 interactive dashboard changes if V19/V18 migrations are already applied.
6. Keep the Vercel Root Directory exactly as:
   taurusprojectcontrol-professional-v20
7. Keep the same Vercel/Supabase environment variables already used by the working deployment.
8. Redeploy Vercel.

V20 package is intentionally kept below 100 source files for simpler GitHub web upload.
Never upload passwords, database passwords, Supabase secret keys, .env files or .env.local files to GitHub.
